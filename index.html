walios

A real Linux userland compiled to native WebAssembly, run by a JavaScript syscall kernel in this tab. No CPU emulation, no server: every command is a wasm program answering Linux syscalls.

checking this browser… Open the terminal

busybox ash on a real pty: pipes, job control, vi, find; plus python3 with numpy, pandas and matplotlib, an in-tab cc (clang 22 + wasm-ld), make, git, jq, lua, qjs, ssh. Files under /root persist in this browser.

How it works

  • Programs are ordinary Linux builds targeting wasm32-unknown-linux-muslwali (WALI): the binary imports wali.SYS_* and the kernel worker answers them with x86-64 struct layouts.
  • Each process runs in its own Web Worker; blocking syscalls park it in Atomics.wait on a shared control block while the never-blocked kernel serves the others. fork() is an Asyncify unwind, memory copy and rewind.
  • The page needs cross-origin isolation for SharedArrayBuffer; on static hosts like GitHub Pages a small service worker adds the COOP/COEP headers and the page reloads once.
  • CPython loads C extensions as PIC wasm side modules through dlopen; package bundles mount lazily on the first import miss.
  • Networking is TCP over a WebSocket (WISP) relay, with relay-side TLS for wget and in-guest OpenSSL for curl, git, ssh and Python.
